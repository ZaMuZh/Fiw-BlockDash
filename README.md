# Fiw BlockDash

Mod Fabric para Minecraft 1.21.1.

## Compilación automática

Cada push a `main` ejecuta GitHub Actions con Java 21 y Gradle 8.10.2. Si la compilación termina correctamente, el JAR aparece como artefacto en la ejecución del workflow **Build Fiw BlockDash**.

## Requisitos del proyecto

- Minecraft 1.21.1
- Fabric
- Java 21

> El código fuente del mod debe estar en este repositorio para que la compilación pueda ejecutarse.
